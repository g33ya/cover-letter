# An Interactive Cover Letter

An interactive cover letter created for my application to the GTM Engineering role at LeanTaaS.

I wanted to build something that reflects both my technical background and my personality!

The website walks through my experiences in software engineering, community leadership, and process improvement, exploring how these interests come together in my approach to problem-solving.

## Built With

- React
- TypeScript
- Vite
- CSS

## Running Locally

Clone the repository and install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
